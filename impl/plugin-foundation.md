## Build

- Target: Skyrim AE **1.6.1170**, SKSE 2.2.6, Address Library (LoreRim: all-in-one 11). NG builds
  one DLL for all runtimes; only AE is tested.
- CommonLibSSE-NG (alandtse, `ng`) as a submodule with the libxse xmake template **or** CMake +
  vcpkg; pick one and write the exact commands in `plugin/README.md`. MSVC (VS 2022), C++23.
- Extra libraries: `spdlog` (comes with CommonLib), `toml++`, a JSON library for the UI snapshot
  (`nlohmann-json` or `glaze`), `PrismaUI_API.h` 1.5.1 (vendored header).
- Every hook through Address Library IDs (`REL::RelocationID` / `REL::ID`) or vtables; no raw
  addresses.
- Unit tests: a separate executable that links only the pure-logic sources (curves, `LevelXP`,
  `k` solver, `levelFromXP`, decay integral, zone split, form rules on fake inputs). Expected
  values for `k` come from `python3 scripts/normalize_conversion.py config/skills/<skill>.toml`.

## Logging

- spdlog file sink: `SKSE::log::log_directory() / "SkillPractice.log"` (Documents\My
  Games\Skyrim Special Edition\SKSE\). New file each start; pattern
  `[%H:%M:%S.%e] [%l] %v`; flush on `warn` and at least once per second (and at once after a
  dump).
- Level from `[log] level` / MCM, changeable at runtime (`spdlog::set_level`).
- Every line starts with a tag, so the log can be filtered:

  | Tag | What |
  |---|---|
  | `[boot]` | plugin version, game version, configs loaded, managed skills, sub-skill count, hooks installed (and which module owned the original), keywords resolved / missing |
  | `[cfg]` | values read, MCM changes |
  | `[save]` | co-save save / load / revert, record versions, counts |
  | `[init]` | start conversion per skill |
  | `[use]` | every `UseSkill` call (debug) |
  | `[ctx]` | context resolution, unresolved awards (warn) |
  | `[xp]` | every award (when `xp_verbose`) |
  | `[main]` | main level writes, external changes |
  | `[time]` | skipped game-time jumps |
  | `[decay]` | per tick summary at trace; level changes by decay at debug |
  | `[class]`, `[spell]` | classification, fallbacks, dumps |
  | `[aim]` | every perturbed projectile / sway start and stop (debug) |
  | `[ui]` | button presses |

- `[xp]` line format (one line, `key=value`, easy to grep):
  `[xp] t=<activeHours> src=<use|debug> skill=<AV> sub=<id> pts=<points> raw=<raw> z=<zone> cur=<a>→<b> floor=<f> pot=<p> peak=<k> U=<u> R=<r> F=<F>`.
- A crash must not lose the lines before it: flush policy above.
