# Skills: per-skill design and perk worksheets

General rules (XP pipeline, main skill from sub-skills, sub-skill dynamics, effect curve,
cross-links, anti-grind, UI, technical notes) are in [`design-v2.md`](../design-v2.md). This folder
holds everything about **specific** skills, so a task about one skill needs only its folder plus
the general sections it refers to (bare `§N` in these files means a section of design-v2.md).

**Files in a skill folder**

- `design.md` — sub-skills, XP rules, effects and open questions of the skill (hand-written).
  Every sub-skill must have its continuous effects stated there, or an explicit "no continuous
  effects" (design-v2 §5.6, Q-DYN-7).
  Where several skills share one design, it lives in a group folder. In `weapons/` (One-Handed,
  Two-Handed, Archery) and `armor/` (Heavy Armor, Light Armor) the skills' perk files are in the
  same folder, prefixed by the skill: `one-handed.perks.md`, `one-handed.perks-removed.md`, …
  `magic/` and `lockpicking-pickpocket-sneak/` hold only the design; their skills' perks stay in
  their own folders.
- `perks.md` — the skill's LoreRim tree perks; `perks-removed.md` — perks removed from the tree;
  `perks-ordinator.md` — Ordinator 9.31 perks not in LoreRim. Generated by
  [`scripts/gen_lorerim_refs.py`](../scripts/gen_lorerim_refs.py) (refuses to overwrite without
  `--force`, so answers written into them are safe); how to read them and background on
  records / overrides / bringing back Ordinator perks: [`perks-guide.md`](perks-guide.md)
  (its background part is [`scripts/perks-notes.md`](../scripts/perks-notes.md)).
