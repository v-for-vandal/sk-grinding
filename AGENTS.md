# Skill Practice Overhaul: notes for agents

SKSE plugin (CommonLibSSE-NG) for the LoreRim 5.0+ mod list that replaces skill progression with
sub-skills. This repository holds the **design** for now; the code comes later.

## Core model (keep this in mind; full text: [`design-v2.md`](design-v2.md) §3, §4, §5)

- **Sub-skills** (`sword`, `ebony-armor`, `missile`, …) are the only thing that earns XP. Each has
  exactly one parent main skill. Each has `current` (0–200, decays without use), `floor` (decay
  stops there) and `potential` (best level reached; below it XP is ×1.5 "recall"). Continuous
  effects and our perks read the sub-skill, never the main skill.
- **Main skill level is computed, not accumulated.** Vanilla skill XP is suppressed. The main
  level is a formula over the levels of its sub-skills: each sub-skill `i` at level `L` is worth
  `M_i(L)` (rises over the first levels, then saturates), the worths are summed and turned into a
  level (§4.4.1). There is **no "XP goes to the main skill"** step. Do not write it that way; say
  "counts towards the main skill" or refer to the formula. The old transfer model is in
  [`old/`](old/) and is superseded.
- **Rust:** the main skill has its own decay `R`, driven by the practice of the whole skill, not by
  each sub-skill's decay (§4.4.3).
- **Concept sub-skills** (`dual-wield`, `with-shield`, `with-magic`) have `k = 0`: they give
  nothing to the main skill, they exist for effects and perks.
- **Cross-links** raise another sub-skill's effective floor; they never move `current` (§6).

## Where things are

- [`design-v2.md`](design-v2.md): general rules.
- [`skills/`](skills/README.md): per-skill design (`design.md`) and perk worksheets (`perks*.md`).
- [`impl/`](impl/README.md): one file per decided mechanism (how it will be implemented). Keep
  them up to date when a decision changes.
- [`research/`](research/): `R-<n>-*.md`, details of research tasks; index in design-v2 §15.2.
- [`config/`](config/): the plugin's config files (all numbers, placeholders for now);
  [`config/skills/`](config/skills/) also drives `scripts/normalize_conversion.py`.
- [`plan/`](plan/): tasks for the implementing agent (first: [`plan/prototype-1.md`](plan/prototype-1.md)).
- [`refs/`](refs/): background notes. [`old/`](old/): superseded designs.

## Conventions

- Docs are in English.
- Questions are `- **Q-XXX-n.** …` with `- **A:**` below. When a question is answered, fold the
  answer into the text as a decision and remove the question.
- Perk worksheet diagrams are generated by `scripts/gen_perk_diagrams.py` (between the
  `DIAGRAM_BEGIN` / `DIAGRAM_END` markers); `skills/block` has hand-drawn ones.
